# Crea't Fest 2026 - Web del curso anterior

## Descripción de la web
Crea't Fest 2026 es una página web estática multipágina desarrollada para un festival ficticio de arte y cultura digital. 
La web incluye las siguientes secciones y funcionalidades:
- **Página principal (index.html):** Hero de bienvenida, calendario del evento, tabla de itinerario, tarjetas interactivas (flip cards) para patrocinadores y FAQ, mapa de contacto y formularios de contacto/registro con validación en JavaScript.
- **Galería (galeria.html):** Un slider de imágenes animado con CSS y un grid de imágenes (2x2) con efecto Lightbox implementado en JavaScript.
- **Páginas legales:** Términos y condiciones, política de cookies y política de privacidad.
- **Diseño:** Totalmente responsive (adaptable a móviles y tablets), con menú hamburguesa, transiciones suaves y un modal de bienvenida que solo aparece la primera vez que se visita la web.

## Tecnologías utilizadas
- **HTML** (estructura semántica)
- **CSS** (Flexbox, Grid, animaciones, media queries, flip cards)
- **JavaScript** (validación de formularios, lógica del lightbox, control del modal de bienvenida y almacenamiento local con `localStorage`).

## Cómo ejecutar en local
No requiere instalación ni servidor. Para verla en tu ordenador:
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` haciendo doble clic en él en cualquier navegador web (Chrome, Firefox, Safari, etc.).
